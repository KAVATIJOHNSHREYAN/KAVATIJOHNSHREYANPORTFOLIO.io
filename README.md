## 🚀 Local Development Setup

To run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/KAVATIJOHNSHREYAN/KAVATIJOHNSHREYANPORTFOLIO.io.git

# Navigate into the project folder
cd KAVATIJOHNSHREYANPORTFOLIO.io

# Open index.html in your preferred browser or start a local live server
# Example using Python http.server:
python -m http.server 8000
```
